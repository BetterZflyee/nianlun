# 年轮 2.3.0 · 看见积累，顺手推进

2026-10-22。兼容 2.2 的绑定、独立记忆空间和执行回执。界面功能小版本，不升级为 3.0。

## 本次变化

- **项目工作台**：撤下默认的大树与分支图。项目关系收为一条概览，点击「探索关系」打开关联矩阵，直接查看每条项目记录连接的里程碑与场地。未建立的关联保持空白。
- **我的待办**：采用筛选、列表、详情三栏。点击标题读取原始正文、截止时间、优先级、创建人、执行人、参与人、活动及原始入口。保留项目匹配、多选、批量完成和写后回读；增加已完成视图。
- **项目记忆**：进入页面先展示真实记忆目录与 Three.js 星空图，不再要求先搜索。按项目归组，支持平移、缩放、节点选择、目录、全文检索与正文阅读。虚线表示标题分组，实线表示已读取正文中的明确引用。
- **能力中心**：按用途分类，区分启用状态与来源目录。点击卡片查看完整说明和路径，多选后批量启用、停用或组合工作流。
- **工作流**：阶段汇报、项目复盘、工作交接三个起点；项目背景→能力→宿主→产物四步表达。DeepSeek 继续使用接续模式，材料准备完毕不等同于工作流已执行。
- **执行记录**：状态总览、分类筛选、紧凑列表和详情抽屉。原轮次恢复仍位于「接入与运行」，通知入口继续保留。
- **统一视觉**：米白与森林绿、统一图标、卡片、抽屉与短过渡。尊重减少动态效果设置；Three.js 完全本地加载，静止时不持续刷新。
- **版本与回退**：侧栏提供版本面板、GitHub 历史版本和安全退出服务入口。保留 2.2.0 固定标签及安装包，支持重新安装旧核心。

## 仍需明确的边界

记忆目录每次读取 120 篇，可继续加载；当前图形最多绘制 300 篇匹配页面，其余仍可从目录和搜索访问。标题归组不是人工确认的知识关系。WebGL 不可用时保留二维图与目录。

待办详情取自 DWS 实际字段；源待办没有正文、时间或姓名时，明确显示未提供，不生成占位业务事实。附件仅显示名称，原文件从源待办打开。

DeepSeek 原生客户端执行仍由用户接续，本版没有偷偷切换到 Codex。升级不会开启已暂停的自生长任务，也不会新增采集来源。Windows 原生安装与真实账号闭环尚未在 Windows 设备验收。
