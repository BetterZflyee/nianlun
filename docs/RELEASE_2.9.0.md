# 2.9.0 · 图文阶段回顾

之前的生成契约把表格或提示框也算作可视化，且模型不能输出 HTML，导致所选 Skill 原有 ECharts 入口无法使用。现在用受校验的 `visual` JSON 围栏连接模型和确定性渲染器。

报告先给出整体判断，再用少量完整面板呈现场地状态或推进关系。图内信息不在正文重复。无数值资料不画完成率，有真实同口径数值才使用柱状或趋势图。

- 状态卡：具体事项、实际状态、下一步、引用。
- 关系图：明确节点和连线，默认静态 SVG；可选 ECharts 交互探索和 Three.js 立体查看。
- 统计图：ECharts SVG 渲染、图例、数值提示、保存 SVG；附静态图和完整数值表。
- 发布：保持单个离线 HTML。精确 CSP 哈希允许内联库，不请求 CDN，不开放模型脚本执行。

图形最多三张；关系最多九个节点、九条边，按明确列序阅读。Three.js 仅点击后创建，关闭释放。不能运行脚本或 WebGL 的预览仍保留静态图、结论和依据。钉钉在线预览是否执行脚本由其容器决定；完整交互以支持脚本的 HTML 浏览器为准。

所选 recap Skill 的 `references/visual-contract.md` 会进入成稿契约。年轮自带公共适配器供未升级的 Skill 兼容使用，用户的私有 Skill 不进入安装包。维护者可在自行备份 Skill 后显式运行 `python tools/sync_recap_visuals.py <Skill目录>`，安装独立的 `scripts/render_visual.py` 和公共图形资源；不会自动修改其他技能。

v2.8.1 标签、安装包、旧报告均保留。已冻结的未完成任务如遇成稿契约变化，会提示按最新资料重新生成，避免在原任务中混入新旧规则。升级不重启定时生长，不修改绑定或宿主。回退使用旧安装包；独立 Skill 如已更新，应同时恢复自己的备份。

验证范围：265 项核心测试、4 项安装包测试、40 项前端逻辑测试；本机浏览器核验图文布局、关系交互、立体查看及 390px 窄屏。详见 [验证记录](VALIDATION_2.9.0.md)。
