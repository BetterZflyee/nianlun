# 年轮 2.7.1 修订说明

日期：2026-10-24

本次修订收起不必要的展示层，让能力管理、工作流配置和执行查询直接进入操作。

| 页面 | 2.7.1 的变化 | 保留的操作 |
| --- | --- | --- |
| 能力中心 | 移除 Three.js “方法星座” | 分类、搜索、详情、目录扫描、单项与批量启用 |
| 工作流 | 移除 Three.js “这次工作的路径”，不恢复旧流程图 | 项目和能力选择、工作与交付要求、提交和宿主接续 |
| 执行记录 | 移除 Three.js “行动时间线” | 分类与状态筛选、任务详情、回执、重试与接续 |

项目工作台、项目关系、待办、项目记忆、接入与运行，以及既有报告路径的可视化继续保留。本次不新增数据来源、不改变报告生成或宿主调用方式，也不迁移 AI 表格、记忆内容和任务回执。

## 验证范围

本说明记录修订范围，不替代验收结果。实际执行的代码、浏览器和安装包检查，以及尚未覆盖的环境，以 [2.7.1 验收记录](VALIDATION_2.7.1.md) 为准；历史平台限制仍见 [使用说明](USER_GUIDE.md)。

## 升级与回退

源码、程序显示和安装包使用 2.7.1。2.7.0 的源码标签、安装包、校验文件及历史发布说明保留，作为本次直接回退版本；更早的 2.6.0 等版本继续保留。

等待正在运行的任务结束，退出本机服务，再安装目标版本。个人绑定、宿主选择、来源授权、记忆与去重回执保留，自动生长暂停状态也保留。回退 2.7.0 会恢复这三个页面当时的三维图景。详细步骤见 [版本管理](VERSIONING.md)。
