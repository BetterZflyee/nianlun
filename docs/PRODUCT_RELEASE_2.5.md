# 年轮 2.5：在自己的记忆星系中探索

年轮沿用现有 AI 表格和独立记忆空间，把「项目记忆」从平面分组散点图升级为三维浏览。每篇页面仍是原来的记忆，每条连线来自已读取的关系，不会因视觉需要自动创造关联。

## 这次可以怎么用

- 旋转星系、缩放或平移画面；点击记忆时镜头飞近，直接阅读正文。
- 搜索已载入页面并定位，使用全文检索查找目录之外的材料。
- 聚焦一层或两层引用，同时查看已载入页面的反向引用。
- 用颜色查看各项目或记忆目录，切换立体星系与舒展星盘，展开画布或暂停漫游。
- 目录先出现，引用分批读取；等待时仍能操作，失败能重试。无图形加速时保留目录阅读。

## 运行与数据范围

本版同时收录项目关系页的桑基视图更新：把里程碑、项目记录和场地的已有关联放在同一张图中，支持搜索、路径聚焦与详情阅读；未关联项单独列出，不猜测连接。

本地 Three.js 渲染，Worker 计算布局，节点与关系合批绘制。首批读取 120 篇，自动预载最多 600 篇目录，可以继续加载，展示上限为 1500 篇。引用只读当前已连接记忆空间；没有运行提取或写入，也没有新增模型调用。关系索引为空或尚未建立时，星图显示页面与颜色分组，不把布局当作知识关系。

视觉交互参考 [Obsidian Galaxy View](https://community.obsidian.md/plugins/galaxy-view) 和其 [官方仓库](https://github.com/Longwind1984/galaxy-view)。本次实现年轮适用的探索流程，未包含该插件的全部预设、标签透镜和路径漫游，也不需要安装 Obsidian。

## 升级与回退

升级不改变宿主、AI 表格绑定、记忆位置与自动生长状态。当前功能版本为 2.5.0，上一版 v2.4.0 标签与安装包保留。回退时先结束正在运行的写入任务并退出本机服务，再安装旧版；不能删除去重和报告回执。
