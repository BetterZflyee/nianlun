# 年轮 2.2 产品使用说明书

版本：2.2.0 本机验收版 · 2026-10-21

年轮围绕正在推进的项目持续工作：获取新信息，更新进度，基于项目资料规划里程碑，维护记忆，并生成阶段汇报。你负责目标、取舍和需要人工判断的事项。业务记录保存在自己的钉钉 AI 表格，长期上下文保存在自己的独立记忆空间。

## 1. 安装与首次接入

1. 解压安装包。Mac 双击“安装年轮.command”，Windows 双击“安装年轮.cmd”。安装器准备个人运行环境；无需预先安装 Python 或记忆引擎。首次下载需要联网。
2. 用“打开年轮”进入本机工作台。不要直接双击程序里的 `index.html`，那样不能连接本机服务。
3. 在“接入与运行”登录本人钉钉，选定账号与组织。已有多个账号时，明确选择；绑定后不要随意切换组织。
4. 粘贴自己的 AI 表格链接，选择初始化四张子表，或映射已有项目主表、里程碑表、场地表和项目记录表。检查预览后执行。
5. 新建独立记忆空间，或连接已有兼容空间。向导会安装需要的记忆组件并验证读写，日常无需管理底层工具。
6. 选择 Codex、Claude Code 或其他宿主。工作流和推理的执行方式以页面显示的能力为准。
7. 选择信息来源、自动动作、时间与时区，指定阶段汇报文件夹。最后完成一个定时负责人的注册及验证。

Windows 提供安装入口，但仍需原生机器验收。Codex 主链路已有历史实测；本轮新功能主要通过隔离测试验证。Claude、WorkBuddy、DeepSeek 的接续方式及验证边界见 README。

## 2. 建立一个能生长的项目

在“项目工作台”创建项目，填写名称、目标、状态和优先级。目标应描述可验收的结果，例如“完成两个试点的上线验收”，而非“继续推进”。

新建表格模板包含“项目目标”和“目标日期”。已有表格可以在绑定向导映射日期字段；若只绑定了备注字段，倒排入口会把日期保存为备注中的“年轮目标日期：YYYY-MM-DD”。目标、日期与计划仍写在 AI 表格里，不另建业务数据库。

项目详情集中展示记录、里程碑和场地。手动修改会检查数据是否已被他人更新；出现冲突时先刷新，再重新编辑。

## 3. 自动生长：让信息持续跟上项目

在“接入与运行”开启定时运行，选定每天的时间和时区。调度器只负责唤醒，核心按保存的时间、开关和执行回执决定本轮是否运行。换宿主时保留一个调度负责人，避免多个旧任务同时写入。

一次完整生长依次执行：

1. 获取启用来源中有权限访问的信息，记录覆盖范围与缺口。
2. 对比已处理的来源编号与内容版本，检索项目历史，由所选 AI 宿主理解变化。
3. 校验依据和对象，写项目记录、里程碑事实及状态，创建或完成本人待办，并回读结果。
4. 开启自动规划时，根据项目资料、目标日期与最新事实更新计划节点。
5. 开启记忆写入时，更新项目当前记忆，同时保留每轮生长档案。
6. 开启“每轮生长后自动更新阶段汇报”时，生成最近七天的阶段汇报并回填主表。
7. 按设置向本人推送摘要；执行记录保留具体结果与失败位置。

相同事实不会反复产生相同记录。听记默认滚动回看近期会议，覆盖晚生成摘要和夜间会议；缺失分页的来源保留补采窗口。没有完成证据的待办不会仅因标题相似而关闭。

运行需要电脑、网络、登录与所选宿主可用；宿主处于接续模式时，任务会等待宿主返回。自动生长不是脱离这些条件的云端常驻服务。

### 暂停与恢复（2.1.1）

在“接入与运行”查看自动生长运行状态及核验时间。Codex 原生任务暂停后，页面显示“宿主原生任务已暂停”，不使用旧的注册回执判断仍在运行。其他宿主保留待核验提示，最近一次唤醒不代表周期任务持续运行。

点击“立即暂停自动生长”即可停止启动新的定时轮次，无需保存配置，即使前一轮有未确认结果也能操作。当前已经运行的轮次不会被强行中断，已提交结果和去重记录保留。“解除本机暂停”只解除本机停止意图；宿主原生任务仍暂停时不会恢复自动执行。

在“接入与运行”的“待完成原轮次”恢复未完成的生长：

1. 有结果待核验时，点击“核验原结果”。它只回读 AI 表格、待办或记忆，核对原来源标记、原编号和内容，不重新提交业务写入。
2. 核验通过后，点击“继续原轮次剩余步骤”。它使用原证据和计划，补做尚未完成的动作，结束后更新原时段的执行记录。暂停状态保持不变。
3. 若待办创建没有返回编号，或摘要发送没有投递句柄，年轮会保留待核，不能仅凭相似标题认定成功，也不会盲目重发。保留原回执，由用户核实实际结果。
4. 配置或组织身份变化、内容冲突、同一来源出现多条记录时，停止恢复并保留证据。先排查这些差异，不删除去重记录来重跑。

同一失败原因反复出现不会重复请求通知；原因变化或恢复时再报告。执行记录仍保留尝试次数与错误。读取失败不会被当作“没有数据”。

AI 表格的单选字段增加选项后，页面会读取新增值，无需重新绑定；原选项删除、改名或字段类型变化仍需检查绑定，不能绕过核验。

工作台、批量汇报和自动规划共用活跃项目范围：已完成、已暂停、暂停、已取消、概念状态不纳入；这些项目的历史记录仍可查看。

## 4. 手动补采与获取项目进度

在工作台点击“让年轮生长一次”，或在项目详情点击“获取项目进度”。

1. 选择开始与结束时间。单次最多 366 天，长时间范围建议拆分。
2. 勾选已启用渠道：AI 听记、群聊 @我、单聊、选定群聊、选定邮箱、可选飞书妙记、宿主人类会话或工作台操作。
3. 从项目详情进入时只分析并更新该项目；全局入口面向全部项目。
4. 点击“采集并更新项目”，等待执行结果。需要宿主接续时，按执行记录中的提示继续原任务。

手动与定时使用同一条处理链，但手动补采不会推进定时渠道的采集游标。已有未完成任务时，先恢复原任务，不用新时间范围覆盖它。

群聊来源要先搜索并选择具体群，邮件来源要从本人邮箱列表中选择一个邮箱。它们默认关闭，不会因为开启自动生长而扫描所有群或所有邮箱。飞书妙记同样是可选来源，需要本机已安装并登录飞书 CLI。

## 5. 里程碑：基于项目资料规划

打开项目，点击“规划里程碑”。先确认项目目标、目标日期，再确认已有项目说明、记录、节点或相关记忆中包含交付依据。

资料足够时，AI 提出交付节点与前置依赖，核心计算日期并核验顺序后写回。只有目标和日期时会说明缺少依据，不强行规划。开启自动规划后，后续生长按新事实调整年轮计划节点。

人工节点、已完成节点和人工修改过的节点保留。不会删除计划中未再次出现的节点，也不会因截止日已过而标记完成。AI 规划是计划建议，报告会把它与已发生事实区分。

## 6. 自动汇报与项目群推进

三种入口使用同一套汇报逻辑：

| 入口 | 使用方式 |
| --- | --- |
| 生长后自动更新 | 开启阶段汇报及生长后更新，每轮按最近七天生成 |
| 固定周期汇报 | 在运行设置中选择每周日期和时间 |
| 手动阶段 / 月报 | 项目详情点击“生成汇报”，选择时间范围；“本月”快捷设置月初至今天 |

年轮从事实、节点与历史记忆组织目标、本期进展、里程碑变化、风险和下一步。你不需要先补写汇报正文。没有记录的情况会说明缺口，区间外历史不会当成本期成果。

生成的 HTML 与 Markdown 保存在本地运行目录，HTML 上传到指定钉钉文件夹，链接回填项目主表。相同期间但有新进展时会刷新内容；写回失败保留回执，不把失败当成功。

要推动项目群协作，在生成结果中点击“发送到项目群”：搜索并明确选择接收群，查看或修改消息预览，再点击发送。DWS CLI 执行投递，年轮查询投递结果；未确认时保留同一请求继续查询，不重复发送。本轮没有默认绑定任何真实群，也没有开启自动群发。

## 7. 独立记忆空间：自动维护，随时检索

开启“写入项目记忆”后，每轮会更新各项目的当前事实、计划和关联记录，并保留每轮生长档案。写入通过记忆引擎完成，并回读验证。无需定期手动整理文件。

在“项目记忆”输入项目名或关键词，可以检索讨论、判断与经验。“补存接入前的项目基线”用于首次接入旧项目或补充历史，不是日常必做步骤。关键词没有命中不代表记忆空间为空。

## 8. 我的待办：与丰声 / DWS 双向同步

“我的待办”读取当前身份通过 DWS CLI 可见的未完成待办。产品不会另建一份待办事实库。

- 自动生长可依据明确事项创建本人的待办，并关联项目记录。
- 页面可以手动创建项目待办。
- 点击完成、确认目标后，年轮在 DWS 中完成同一项待办，回读验证，再同步已关联记录的状态。
- 后续会话出现明确完成证据且匹配唯一时，可以按开启的自动完成规则处理。

这里只表示当前 DWS 身份可见的待办，不承诺包含丰声所有其他业务入口的任务。部分写入失败时，执行记录会保留成功部分和未完成部分。

## 9. 能力中心与工作流

能力中心会列出适配器可读取的本机 Skill。点击“选择 Skill 根目录…”使用系统文件夹选择器；支持最多 20 个根目录，递归扫描其中的 `SKILL.md`。手动输入路径作为备用入口。可以同时指定 Codex、Claude 和自己的技能目录。

点击“保存并重新扫描”，再选择启用需要的能力。加入目录不会自动启用所有技能；路径不会改写宿主的全局配置。迁移电脑后，在页面重新指定当地路径即可。

“分析”使用选定方法分析项目资料；“运行工作流”按宿主能力执行或交回宿主接续。原有宿主权限确认继续生效，年轮不替你批准未知动作。

## 10. 执行记录与恢复

有实际变化、缺口或故障时先查看执行记录。重点看来源覆盖、已核验写入、待处理事项、报告链接和宿主等待状态。

| 情况 | 处理 |
| --- | --- |
| 页面只有文字或无法连接 | 用“打开年轮”启动，不直接打开源 HTML |
| 尚未开启来源 | 在接入与运行配置后保存；手动补采不能越过来源开关 |
| 目标日期未绑定 | 给主表添加日期字段并重新绑定，或使用已有备注字段 |
| 表结构变化 / 数据冲突 | 重新读取与绑定，或刷新对应项目；不强制覆盖 |
| 等待 AI 宿主 | 打开任务交接材料，在相应宿主完成，再继续原任务 |
| 上传或发送结果未知 | 保留回执，先核验；不要反复新建任务 |
| 部分渠道缺页 / 登录失败 | 修复该渠道连接后补采，其他已核验结果保留 |

## 11. 升级与数据归属

2.2 保留既有绑定与旧版资料。安装器备份旧核心；个人配置、记忆空间、表格和去重回执不随代码替换。新增群聊、邮件及两个自动动作需要在页面明确开启。

本地证据与运行目录可能包含私人工作内容，不要提交到开源仓库。推理所用证据会交给选定 AI 宿主，按该宿主的服务和设置处理。项目主数据自有不代表全部计算都在本机。

## 2.2：快速处理与项目关联

打开项目后，先看到生长树。点击节点可查看详情、聚焦关联或编辑；“显示全部”恢复全图。“翻面 · 桑基关联”按项目记录、里程碑、场地排列。没有明确关系的项单独保留，需在编辑中补关联；共同记录仅作为推导依据，不代表场地已经升级。项目名称、项目编码和场地编码来自原表，未绑定编码时如实显示未填写。

项目记录右侧“快速处理”直接保存所选状态并回读。勾选记录后，可统一选择状态再批量更新。每批最多 100 项；部分失败会显示具体项，成功结果保留。手动关闭记录表示你已确认该事项解决，不会等到下一次自动生长才写回。

“我的待办”可按项目筛选、搜索、勾选或选择筛选结果，再点击“完成所选待办”。系统会逐项完成本人未完成待办，并核验结果。已有明确记录关联的待办同步更新相应记录；从标题括号推断的项目归属不会自动猜记录。

## 2.2：任务状态、DeepSeek 接续与通知

任务面板显示当前阶段、步骤历史和耗时，不显示虚构的完成百分比。关闭弹窗不会取消任务；右上角通知或执行记录可以回到原任务。

DeepSeek 模式下，出现“等待你的宿主”时：

1. 复制接续请求，在 DeepSeek Harness 中提交。
2. 由它读取请求并通过年轮的返回契约提交分析结果。
3. 回到原任务，点击“检查回复并继续”。未收到回答会说明原因，收到后继续原任务。

等待不是后台持续推理；不用反复创建新任务。当前没有已验证的 DeepSeek 内嵌调用接口，工作流仍在宿主处理权限和工具执行。

运行暂停状态和原轮次恢复操作移至“接入与运行”。执行记录保留操作历史、来源覆盖和分类筛选。通知同时展示页面任务与定时轮次，不额外向外发送消息。

## 2.2：能力、记忆和报告

能力中心点击“选择 Skill 根目录”，系统递归扫描其中的 SKILL.md，跳过依赖和 Git 目录。勾选后批量启用，可在工作流中选多项能力。文件夹选择器不可用时可展开备用路径输入。

加载自己的 transcript-visual-recap 文件夹后，点击该能力的“用于阶段汇报”。以后生成汇报会结合表格与相关记忆，并使用该 Skill 的可视化渲染。若 Skill 或 Node 不可用，会明确报错并保留草稿；不会伪称渲染成功。默认报告仍可使用年轮自身的 HTML 输出。共享安装包不包含个人 Skill、记忆或登录信息。

项目记忆页左侧选择项目，可展开命中的记忆页面及明确引用，点击节点或卡片读正文。关键词未命中不代表库为空；超长或无法完整读取的内容会注明。搜索可继续使用简称或具体议题。

规划里程碑前，先采集项目资料或接入已有记忆。只有目标和截止日期时不强行编排。已有人工节点及已完成节点继续保留。

## 2.2：CDBI 场地接入

“接入与运行 → 丰景台 CDBI”先检测已安装 CLI，再登录。若未安装，可由组织提供当前系统的 HTTPS 单文件下载地址和 SHA-256，在向导填写后安装；已有文件可直接指定。没有当前系统的官方包时显示待接入，其余项目功能仍可用。Mac 和 Windows 安装入口均已实现，Windows 原生运行仍需实机验收。

打开项目的“场地 → 从 CDBI 获取场地”，搜索并选择授权数据集，读取字段，映射场地编码与名称，可按区域等字段限定范围。预览只读取首 100 条，达到上限时请缩小范围；勾选后导入。已有同项目同编码场地保留，不覆盖原表内容。现有场地表未绑定编码字段时需通过接入向导补齐。
