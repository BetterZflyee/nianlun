本机只读实测：记忆首批目录约 1.4 秒、单篇正文约 0.9 秒、待办列表约 3.6 秒、详情约 2.9 秒。仅代表该次网络、机器与数据条件。

自动测试：195 项核心回归（包含新增目录格式、分页范围、换空间后清除可读页面范围、正文上限、待办身份范围、详情字段白名单、退出认证与忙碌拦截）以及 4 项打包/安装注册测试。打包测试检查确定性 ZIP、文件哈希、许可与隔离安装注册。前端脚本通过语法检查，隔离验收浏览器未发现控制台错误。

[GitHub CI](https://github.com/BetterZflyee/nianlun/actions/runs/39642117397) 的 7 组检查全部通过：Linux、macOS、Windows 的 Python 3.11/3.12，以及 Linux 的 Python 3.14。首次 Windows 检查暴露旧测试硬编码 `/` 分隔符，已改为比较规范化后的路径组成；没有跳过测试。

发布前额外核对：公开文件检查、安装包 SHA-256、安装后源码一致性、自生长暂停和原宿主选择保持。个人配置、截图、会话令牌与实际项目内容不进入公开仓库。

边界：没有执行真实待办批量完成、真实自动生长、消息推送或 DeepSeek 客户端推理。没有在 Windows 真机进行原生安装与业务操作；跨平台自动测试与原生验收分别记录。响应式样式已实现，主验收视口为桌面 1280×720。
