## 边界与回退

此版本没有把所有 DeepSeek 工作流改成自动执行；采集决策和工具工作流继续按原方式接续。Windows 命令解析与服务器行为有自动测试覆盖，Windows 原生 dsh 登录和业务写回仍需真机验收。headless 与桌面 profile 可配置不同模型；年轮不覆盖这些设置。

GitHub 保留 v2.3.0 源码和安装包。回退前等待报告发布结束或停止生成，退出本机服务后安装旧版；保留配置、任务材料、报告上传回执及已读记录。公开仓库不包含个人配置、报告内容、记忆材料、宿主认证或运行日志。
