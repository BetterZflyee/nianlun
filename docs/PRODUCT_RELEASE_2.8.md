# 年轮 2.8：DeepSeek 文档工作流自动执行

填写要求、选择项目和方法后，点击「交给 DeepSeek 执行」，无需再复制接续请求。年轮准备项目事实和相关记忆，加载所选方法说明，DeepSeek 生成正文，年轮保存可阅读和下载的成果。

- 看进度：项目资料、所选方法、相关记忆、DeepSeek 执行、保存结果五个阶段，附耗时和处理步骤。
- 可中断和重试：停止生成，或在网络失败、服务中断后重试原任务；冻结材料和已生成正文保留。
- 看结果：工作流页面、执行记录、右上角通知都能查看正文，下载 Markdown/HTML。
- 保持边界：分析、复盘、交接、文档生成自动完成；对外发送和业务写入仍使用对应入口。不会自动运行所选 Skill 的脚本或任意工具。

这是 2.8.0 功能小版本。2.7.1 的源码与安装包保留，升级不切换宿主、不改业务数据、不恢复暂停的定时任务。实际验证与平台限制见 [验收记录](VALIDATION_2.8.md)。
