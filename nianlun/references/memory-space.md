# 独立记忆空间

独立记忆空间用于保存项目讨论、判断、经验与历史总结。它由用户拥有，独立于某个 AI 宿主；更换宿主后，仍可使用同一份项目记忆。AI 表格继续保存项目、里程碑、场地和记录等管理事实。

年轮可以创建专用空间，也可以连接兼容的已有空间。接入过程会验证写入、回读和检索；已有目录和绑定保留，不能通过改名或重新初始化覆盖历史记忆。

## 当前实现与兼容范围

当前版本使用 **GBrain** 作为记忆引擎，安装器负责准备依赖。连接已有空间时，需要选择已有 GBrain 工作目录；其他记忆工具的目录目前不能直接接入。配置目录选项对应 `GBRAIN_HOME` 的父目录，留空时使用该用户的默认配置。

“独立记忆空间”是产品能力名称，不表示年轮重新实现了 GBrain，也不表示已经支持多种可替换的记忆引擎。实际命令、配置键、路径和现有数据格式保持兼容。第三方组件仍按其上游许可证使用。

新建空间默认位于 `~/.local/share/nianlun/memory`。换电脑时需迁移或重新连接记忆目录；仅复制安装包不会携带个人记忆。公开分发包不包含用户的记忆内容。
