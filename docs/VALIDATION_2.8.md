# 2.8.0 验收记录

日期：2026-10-24。基线：v2.7.1。范围：DeepSeek 文档工作流自动执行、进度、停止、重试与本地产物查看。

## 本机真实宿主调用

使用本机已安装的 dsh 0.2.0-rc.2、headless profile，执行一轮合成项目交接摘要。项目表为隔离夹具，未读取或改写用户真实业务表。返回正常 completed、退出码 0、tools=0 确认，生成 Markdown 与 HTML 文件并回读核验。适配器耗时约 3.7 秒，仅代表此次小样本，不作为性能承诺。

## 自动与浏览器验收

- 本机 245 项核心测试、4 项安装打包测试、37 项图形模型测试通过；工作流新增 12 项回归测试。
- 覆盖宿主分流、所选方法与引用、记忆材料、生成和文件核验、输出 HTML 转义。
- 覆盖失败重试保持同一任务与冻结上下文、服务重启中断恢复、重复请求、配置或宿主变化拒绝复用、未启用方法与不完整表格拒绝生成。
- 覆盖排队/运行中停止、取消后恢复、生成成功但保存失败时复用适配器缓存、完成后通知重新未读。
- 隔离浏览器完成提交、阶段与耗时展示、模拟网络失败、原任务重试、离开工作流页面继续运行、通知打开结果、HTML 下载与停止流程。未发现浏览器控制台错误。

## 本机升级

安装版本已更新为 2.8.0，并生成可回退的升级备份。升级前后 191 个已有配置与状态文件的 SHA-256 一致；所选 DeepSeek 宿主、业务绑定和定时任务暂停状态保留。新版页面已核验「交给 DeepSeek 执行」入口；旧接续任务作为历史记录保留，不自动重跑。

## 能力边界

自动流程读取已绑定表格和相关记忆，以所选 Skill 说明及目录内 Markdown 引用为方法，交付分析与本地文档。它不执行任意 Skill 脚本、发送消息或写业务表。完整阶段汇报仍使用已有上传与主表写回入口。未接入记忆会提示，已接入但检索失败不会静默忽略。

Windows/macOS/Linux 包含统一 Python 实现；本轮真实 dsh 调用和浏览器验收在 Mac 完成，Windows 原生宿主调用仍待实机验证。模型质量与耗时受输入和用户宿主配置影响。旧工作流接续记录不自动转换执行，v2.7.1 包和标签保留供回退。
