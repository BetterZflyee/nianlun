# 维护路线

Issues 是任务入口，PR 是修改与验证记录，Release 是可安装版本。下列事项尚未全部完成；按优先级逐项验收，完成后更新这里的状态与对应 Issue。

| 优先级 | 任务 | 完成标准 |
| --- | --- | --- |
| P1 | Windows 完整安装与升级验收 | 在原生 x64 Windows 从零安装、登录、初始化四表、连接 GBrain，完成一轮受控写入与回读；重复安装保留配置，路径包含空格和中文；记录 ARM64 验证状态 |
| P1 | 单轮执行预算与可恢复超时 | 配置整轮时间预算；超时不会误标完成、丢失待办回执或推进失败来源水位；下次接续同一轮 |
| P1 | 钉钉消息采集完整性 | 补充可用接口的分页；到上限时明确 partial，保存继续采集所需信息，不声称覆盖所有聊天 |
| P2 | Claude Code 真实推理验收 | 在已登录客户端完成检索、分析、无变更轮次与受控写入，验证无工具越权和无隐式宿主回退 |
| P2 | WorkBuddy / DeepSeek 原生接续验收 | 在两个实际客户端分别完成 waiting_harness 往返、结果校验和同轮恢复；调度注册与一次 tick 分开验证 |
| P2 | 飞书非空妙记验收 | 使用本人拥有的真实测试妙记，覆盖分页、完整逐字稿、重复采集与已存在待办去重；不公开会议内容 |
| P2 | 安装器签名与分发体验 | 明确 macOS 签名及 Windows 发布方式；验证首次启动，不要求关闭系统防护 |

维护过程中，优先处理越权、数据丢失、重复写入和安装阻断问题。跨平台 CI 通过仅证明隔离测试通过，不替代真实账户和设备验收。
