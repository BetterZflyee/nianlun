# 2.9.1：邮箱读取反馈与验证

过去点击“读取我的邮箱”后，成功返回的邮箱只出现在下拉菜单中，页面仍停留在占位项，也没有明确的成功提示。现在加载过程、账号数量和当前选择都会显示在邮箱旁；仅一个邮箱时预选在表单中，多个邮箱需要用户选择。

新增“验证邮件读取”，依次检查当前身份下的邮箱、最近 24 小时的邮件列表和一封邮件正文。该动作只读，不发送邮件、不标记已读、不保存正文、不启用采集。没有近期邮件时只确认列表查询成功，不宣称正文已验证。

正式采集增加列表分页及逐封正文进度。一封读取失败时显示已成功与失败数量，保留补采窗口，不把缺失数据当作空数据或完整覆盖。缺失邮箱列表结构、身份不匹配和不完整正文均不宣称成功。

使用顺序：接入与运行 → 读取我的邮箱 → 确认下拉框 → 验证邮件读取 → 勾选“我选择的邮箱” → 保存运行设置。读取或验证本身不会保存设置，也不会恢复已暂停的自动生长。
