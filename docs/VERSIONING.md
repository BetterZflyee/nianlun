# 年轮版本管理

从产品 2.0 起，大版本用于里程碑发布，小版本用于持续改进。当前功能小版本为 **2.5**，程序与安装包使用 **2.5.3**，不命名为 3.0。

| 编号 | 使用场景 | 示例 |
| --- | --- | --- |
| 主版本 | 产品定位、数据契约或核心使用方式发生里程碑变化 | 2.x → 3.0，需要明确迁移说明 |
| 次版本 | 在现有产品上增加完整功能，兼容既有数据 | 2.0 → 2.1 |
| 修订版本 | 缺陷修复、兼容性修复、小幅文案修订 | 2.1.0 → 2.1.1 |
| 材料修订 | 同一功能版本的排版与讲稿修改 | 2.1-r1、2.1-r2 |

历史程序使用 0.5.x，历史发布材料使用 1.0 / 2.0。2.1 是统一编号的起点，不重写历史标签或把旧程序冒称为 2.0。现有 0.5.3 配置继续可读，新增来源及自动动作不会因升级被默认开启。

每次发布保留：源码提交、安装包与 SHA-256、变更记录、验收范围、使用说明、发布材料及演讲时长。旧安装包与旧材料保持原文件名和内容。2.1.1 保留为旧版修订候选，2.2.0 保留为界面回退基线；当前 2.5.3 为修订发布候选。真实账号的新渠道采集、Windows 原生安装、不同宿主端到端验收应分别记录，不用单元测试替代。

发布前运行业务测试、安装包测试与公开文件检查。新版本安装保留配置，并备份原核心；运行中的生长任务须完成或明确恢复后再切换核心。回滚使用安装备份，保留原配置和执行回执，不能删除去重记录来“重新运行”。

### 2.2.0

本轮在 2.1 修订基础上加入项目关系可视化、批量处理和 CDBI 接入，属于功能小版本。原计划的 2.1.2 读取与交互修复随 2.2.0 一并交付，不覆盖 2.1.0 / 2.1.1 安装包。大版本保留给产品架构或核心契约的里程碑变化。

### 2.3.0 与回退

2.3 是界面和交互的小版本，配置与业务数据格式兼容 2.2。`v2.2.0` 是界面重构前的固定回退基线，不移动标签。每个版本发布源码、安装 ZIP、SHA-256 及验收边界。

回退步骤：先暂停自生长并等待写入完成，在侧栏「版本与回退」退出本机服务，然后下载并核对目标版本安装包，运行其安装器，再用「打开年轮」重新启动。安装器保留配置和去重回执，原核心进入安装目录的 `backups`。不要清空运行目录，不通过删除回执重跑旧任务。关闭浏览器标签页并不等于退出本机服务。

### 2.4.0 与回退

2.4 增加 DeepSeek 自动报告和通知已读管理，不改变绑定与宿主选择；v2.3.0 为本次回退基线。旧版仍可读取配置，但不会自动处理新版报告适配器。回退前等待报告上传、写回结束，或在生成阶段停止；保留任务目录、报告回执和已读记录。按上面的退出、安装、重新打开步骤回退，不能删除回执后重发。

### 2.5.0 与回退

2.5 增加三维记忆探索与只读引用适配，不迁移或改写记忆内容。v2.4.0 为本次回退基线，保留源码标签和安装包。后台引用读取完成或暂停后，退出本机服务再安装旧版；原配置、报告回执、通知已读和自动生长暂停状态保留。

### 2.5.1 与回退

2.5.1 增加关系图排列偏好，并将绘图替换为 ECharts。项目表、记忆内容和调度配置没有迁移。v2.5.0 为回退基线，源码标签及安装包继续保留。完成正在运行的任务后，退出工作台服务，再运行 2.5.0 安装器即可恢复旧程序；旧版忽略新增的本地排列偏好。

### 2.5.2 与回退

2.5.2 修复阶段汇报重复堆叠资料，增加精简成稿检查并调整所选 Skill 的版式。旧报告、回执和原始材料不删除。v2.5.1 为回退基线；停止工作台服务后安装旧版即可恢复代码。升级不恢复自动生长、不更换宿主或数据绑定。

### 2.5.3 与回退

紧凑交互报告属于 2.5 系列修订，旧报告及旧样稿保留。v2.5.2 为回退基线；升级不更换个人 Skill、不恢复自动生长、不改写已有云端报告。
