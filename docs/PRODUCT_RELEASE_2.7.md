# 年轮 2.7 产品发布说明

**从看见工作，到进入工作。**

2.7 把任务相关的 Three.js 视图扩展到各主页面。待办、能力、工作流、执行记录和接入配置各自表达自己的数据，点选后通向对应操作。项目记忆围绕全景、项目范围、真实引用邻居与侧边阅读展开。

## 每个页面，回答一个具体问题

| 页面 | 图景帮助回答的问题 | 点选后的动作 |
| --- | --- | --- |
| 项目工作台 | 有哪些项目？记录具体关联到哪里？ | 进入项目，阅读记录、里程碑或场地详情 |
| 我的待办 | 待办集中在哪些项目？ | 按项目筛选，再查看详情或批量处理 |
| 项目记忆 | 这个项目积累了什么，下一条依据在哪里？ | 聚焦真实引用邻居并阅读正文 |
| 能力中心 | 已加载哪些类别的方法，有多少已启用？ | 筛选类别，查看和管理具体能力 |
| 工作流 | 本次用什么背景、方法和宿主，准备交付什么？ | 回到相应表单，核对后提交 |
| 执行记录 | 最近执行了哪些任务，各自是什么状态？ | 打开实际任务进度、错误和回执 |
| 接入与运行 | 工作空间保存了哪些连接配置？ | 定位表格、记忆、宿主或调度设置 |

图景可以收起，已有列表、详情、编辑与批量操作继续承担完整工作。点选本身不完成待办、不发送消息、不重试任务，也不改变数据绑定。

## 记忆先能读懂，再继续探索

从全景选项目，从项目选记忆，再沿已读取的真实引用阅读邻居。正文在侧边展开，搜索和目录提供直接入口。默认关闭自动漫游，避免阅读时画面不断移动。

项目归组沿用现有匹配规则，真实引用与同组关系分开解释。没有读取到的边不补造，孤立记忆仍可打开；分批载入、上限和读取故障继续明确显示。

## 让画面遵守数据边界

待办节点按真实项目匹配聚合，能力节点按已加载分类聚合；项目关系只连接记录中明确保存的关联。执行时间线按时间组织，不暗示任务依赖。工作流是提交前预览；接入连线表示配置存在，不冒充登录、网络或宿主可执行性核验。

新增共享场景最多显示 80 个节点和 320 条显式关联，超出部分提示范围。点的大小仅在对应计数场景表达数量，不用于虚构项目完成度或重要性评分。

## 默认静止，随操作变化

新增任务图景没有持续自动转动，只在交互、数据或尺寸变化时绘制。拖动旋转、滚轮缩放、复位与键盘按钮可并行使用；WebGL 不可用或上下文中断时保留可操作的目录。离开视口、隐藏页面和切换页面有对应的暂停或资源释放处理。

实现约束不等于所有设备的性能保证。浏览器、平台和业务验证范围见 [2.7 验收记录](VALIDATION_2.7.md)，公开项目的参考依据见 [可视化参考核验](UI_RESEARCH_2.7.md)。

## 兼容升级，保留回退

2.7.0 是功能小版本，回退基线为 2.6.0。用户的数据继续保存在自己的 AI 表格与独立记忆空间；宿主、来源授权、配置和回执保留，升级不恢复已暂停的自动生长。

回退时先等待运行任务结束并退出本机服务，再安装保留的 2.6.0 安装包。详细操作见 [版本管理](VERSIONING.md) 与 [使用说明](USER_GUIDE.md#27各页面的任务图景与记忆阅读)。
