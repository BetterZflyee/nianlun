# 年轮 2.2.0 · 让工作跟上项目的变化

2.2 是 2.1 的功能小版本。业务数据仍在用户自己的 AI 表格和独立记忆空间；工作台负责操作、关联展示与执行回执，不另建业务库。

## 这一版如何推进项目

在项目页，先用生长树看节点关系；翻面切换桑基关联布局，查看记录、里程碑与场地之间的流向。点击节点可聚焦其直接关联并编辑。表内关系为实线，共同记录推导的关系为虚线，不把这种关系描述为已经完成场地升级，也不把线宽当完成率。

处理记录无需反复打开弹窗：每行可直接改状态，勾选后可批量处理。新信息先与原记录比对，同一事项复用原记录；后续明确解决时更新原记录状态，保留历史与解决依据。同名歧义和不明确完成仍待核。

待办按标题开头的 `[项目]`、`【项目】` 或中英文圆括号匹配唯一同名项目。支持按项目筛选、多选完成。标题推断只建立项目归属，不猜测它对应哪条问题记录；已有明确记录关联时才同步关闭记录。

## 生长、记忆与汇报

采集、分析与写回分别显示阶段、用时和处理历史。关闭弹窗不取消任务；右上角通知可回到原任务。DeepSeek 保留宿主接续：准备请求、宿主回答、继续原任务，页面不会把等待误报为持续推理。

项目记忆按项目列出相关页面，展示明确引用构成的关系图，点击即可读正文，再进行关键词检索。这是项目关键词命中范围，不代表已经穷尽整个知识库。

阶段汇报同时读取项目表、记录、里程碑与相关记忆页面。接续期间固定输入证据，事实变化时阻止过期报告写回。可在能力中心将本机 `transcript-visual-recap` 设为汇报方法，使用其可视化渲染与编辑层。该私人 Skill 不放入公开安装包。

里程碑从“只给截止日倒排”调整为“基于资料规划”。先有记录、现有交付节点、项目说明或记忆依据，再结合目标日期规划；资料不足时提示补齐，不强行输出一套日期。

## 接入和日常运行

能力中心可选择文件夹，递归读取 Skill；支持批量启用与多能力工作流。当前 DeepSeek 无已验证的内嵌执行适配器，因此保留接续，不启动未经验证的私有接口。Codex 原有页面执行仍可用。

接入与运行集中显示调度状态和待完成原轮次。执行记录用于回看历史和分类筛选，通知铃铛聚合完成、故障和等待处理状态。升级保持现有定时任务暂停。

CDBI 是可选场地来源。检测已有 CLI 后可登录、选择数据集、映射编码和名称、限定范围、预览导入。没有安装时，通过组织提供的当前系统单文件地址与 SHA-256 安装；不会猜测企业安装包或附带企业凭据。

## 本轮选择与边界

| 问题 | 本版选择 | 原因 |
| --- | --- | --- |
| 项目关系难以理解 | 树结构与三列关联流，并支持点击聚焦 | 保留业务关系，不依赖云端图服务 |
| 桑基图是否表示流量 | 固定线宽，仅表示关联 | 当前没有可证明的流量或权重 |
| 直接调用 DeepSeek | 暂保留接续，明确步骤与任务状态 | 当前只有接续契约，未验证直接调用与权限接口 |
| 里程碑输入不足 | 先检查资料依据 | 目标日期本身不足以推导真实项目阶段 |
| Windows CDBI | 校验安装入口已实现，需组织提供 Windows 包 | 已掌握的组织分发清单仅含 Mac ARM64，不猜测其他平台 |

关系视图参考了 [d3-sankey](https://github.com/d3/d3-sankey) 的分列流向，以及 [Cytoscape.js](https://github.com/cytoscape/cytoscape.js) 的节点与边交互；[force-graph](https://github.com/vasturiano/force-graph) 适合自由网络探索，但本版优先固定业务层次，避免节点漂移妨碍处理。当前采用本地 SVG 实现，没有引入这些库或外部脚本。
