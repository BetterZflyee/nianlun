# 2.7 验收记录

日期：2026-10-23。范围为七个主页面的任务图景与记忆探索交互，继承 2.6 的业务处理与 2.5.3 的报告实现。

## 浏览器验证

使用隔离本地测试后端：6 个项目、18 项待办、9 项能力、360 篇记忆及显式引用、3 条执行记录。未触发真实采集、消息、待办完成或报告生成。

- 项目工作台显示 Three.js 概览；项目详情的紧凑关系图有 12 个真实条目、8 条明确关联，点选打开相应记录详情。
- 我的待办按项目聚合，点击“配送协同”将列表筛为 3 项；可收起图景并查看执行人、活动和完整待办详情。
- 能力中心点击“数据与分析”筛选到对应能力；已有批量管理与目录入口保留。
- 工作流选择项目和能力后，四步路径同步更新。图中路径仅为提交前预览，没有实际执行任务。
- 执行记录按时间和状态呈现，搜索无结果再清空能恢复；点选节点打开对应任务回执。
- 接入与运行点击 AI 表格节点定位并聚焦表格绑定区域；不完整的初始时间配置不再导致整个页面报错。
- 项目记忆从全景进入项目分组、目录搜索、正文和真实引用；支持一跳/两跳、返回全景及结构化正文。后台索引仅更新引用区域，保留阅读与选择状态。
- 390 × 844 窄屏验证记忆目录、星图、打开正文后的可见性以及待办布局；无页面横向溢出。

## 实现与数据边界

新增任务图景按需绘制、最多 80 个节点及 320 条明确关联；页面导航销毁资源，隐藏及离开视口时暂停绘制。记忆图默认关闭漫游，按目录和真实引用组织；项目归组是标题匹配，不能当成正式业务绑定。

待办/能力图不生成依赖，执行顺序不代表任务依赖，接入图明确区分保存配置与连接健康。新安装默认 generic 宿主不算已保存配置。新增共享场景与现有星图继续使用包内固定版本 Three.js，没有新 CDN 或数据外传接口。

代码复审覆盖异步导航隔离、引用读取重试、片段与完整正文缓存区分、键盘焦点、可操作的 WebGL 降级和几何资源释放。未在原生低端设备做帧率/GPU 内存基准，未在浏览器强制制造 WebGL 上下文故障；不能据此承诺所有设备性能。
